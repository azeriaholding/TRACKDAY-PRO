# TRACKDAY-PRO
TOOLS FOR MOTORBIKE TRACKDAY LIKE MOTORSPORT ENGINEERING

![Licencia](https://img.shields.io/badge/Licencia-Copyright-yellow)
## 🚀 Características Principales
**Base de Datos de Circuitos:** Información detallada de trazados españoles (MotorLand, Jerez, Ricardo Tormo, etc.), incluyendo desarrollos recomendados y puntos clave de adelantamiento.
- **Calculadora de Setup de Suspensiones:** Algoritmos que calculan precarga, compresión y rebote basados en el peso del piloto y el modelo de moto.
- **Diagnóstico de Manejo:** Herramienta interactiva para corregir problemas como subviraje, sobreviraje o hundimiento excesivo en frenada.
- **Gestión de Neumáticos:** Base de datos de presiones (frío/caliente) y temperaturas óptimas para los compuestos más usados en competición.
- **Diagnóstico Visual de Desgaste:** Guía para identificar *cold tear*, *hot tear* y problemas de geometría a través del desgaste de la goma.

## 🛠️ Tecnologías Utilizadas
- **React 18:** Para una interfaz reactiva y rápida.
- **Recharts:** Visualización de datos y gráficas de telemetría.
- **CSS3 Personalizado:** Modo de alta visibilidad diseñado para su uso en paddocks con luz solar directa.
- **Babel Standalone:** Permite la ejecución del código sin necesidad de procesos de compilación complejos.
